# Как работает шапка и первый блок

## Из каких частей состоит страница

`AppComponent` — главный компонент. В его HTML находятся два других компонента:

- `<app-navbar />` — шапка сайта;
- `<app-hero />` — первый большой блок с заголовком и формой.

Так страницу проще читать: у шапки и первого блока свои HTML и SCSS файлы.

## Как выводится название компании

В `navbar.component.ts` есть свойство:

```ts
companyName = 'РУМТИБЕТ';
```

В `navbar.component.html` оно выводится так:

```html
{{ companyName }}
```

Двойные фигурные скобки — это интерполяция Angular. Angular берёт значение свойства из `NavbarComponent` и показывает его в шаблоне. Чтобы поменять название, достаточно изменить строку в `companyName`.

## Где находятся стили

`navbar.component.scss` отвечает за шапку, а `hero.component.scss` — за первый блок. Общие простые настройки страницы находятся в `src/styles.scss`.

Фоновая фотография подключена из `public/mountains-bg.jpg`. Браузер загружает файлы из папки `public` по пути от корня сайта, поэтому в стиле указан путь `/mountains-bg.jpg`.

## Как открыть страницу

В папке проекта запусти:

```bash
npm start
```

Затем открой `http://localhost:4200`.

Поля выбора и кнопка сейчас показывают макет. Кнопка пока не запускает поиск.
